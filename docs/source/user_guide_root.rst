.. _user_guide:

User Guide
#####################

The following guide is meant for users of the web interface of Kaapana, providing an overview of the different views and how to use them.
This includes platform administration as well as user-specific features.
If you want to develop extensions or modify the web interface, please refer to the :ref:`Extension Development Guide<develop_guide>`.
For information on how to install Kaapana on a :term:`server`, please refer to the :ref:`Installation Guide<installation_guide>`.

Start with :ref:`user_guide_navigation` for a tour of the sidebar (platform info, user account, settings, theme toggle, notifications and project selection), then use the sections below for each part of the interface.
